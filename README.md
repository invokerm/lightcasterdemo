# 🎮 Light-Caster

**Light-Caster** is a strategic puzzle game built with **Dart**, where every move matters. 💡

🎯 **Move, aim, and guide objects to their correct points to complete each level.**
🧩 Solve unique challenges, discover new mechanics, and progress through increasingly difficult levels.

### ✨ Features

* 🎯 Point-based movement & objectives
* 🧩 Challenging puzzle mechanics
* 📈 Progressive level difficulty
* 🎨 Clean & modern visual design
* ⚡ Smooth gameplay experience
* 🔊 Immersive sound & effects

**Think. Move. Reach the point. Master the level.** 🚀
